# MedTracker

MedTracker is an app developed as part of the ASEP project to streamline medication tracking and reminders.

## Tech Stack

- **Frontend**: [Flet]  
- **Database**: [Firebase]  
- **Backend**: [FastAPI] / [Flask]  
- **Notification System**: [Plyer] 
- **Hosting**: [Heroku] 

## About the Project

The goal of MedTracker is to provide an intuitive platform for users to track their medication schedules, set reminders, and ensure compliance with their prescriptions.
